- Números a Fichero
Programa Java que genera un archivo de texto con secuencias numéricas incrementales basadas en un número introducido por el usuario.

Descripción
El programa solicita un número al usuario y genera un archivo salida.txt donde cada línea contiene una secuencia de números del 1 hasta el número de línea correspondiente.

Funcionalidades
  - Entrada interactiva: Solicita un número entero al usuario mediante consola
  - Generación de patrones: Crea secuencias numéricas triangulares de forma dinámica
  - Escritura eficiente: Utiliza BufferedWriter para optimizar la escritura en el archivo
  - Construcción optimizada: Emplea StringBuilder para gestionar la concatenación de cadenas
  - Manejo de excepciones: Gestiona errores de I/O durante la creación del archivo

Estructura del Proyecto
  - NumerosAFichero.java - Clase principal que gestiona la entrada del usuario
  - GenerarLineas.java - Genera las secuencias numéricas para cada línea
  - GeneradorFichero.java - Escribe las líneas en el archivo de salida
